Work with your agents, side by side.

Why “Wart”? In German, a Wart is the caretaker who keeps things in order: the Platzwart tends the pitch, the Hauswart the building. CodeWart tends your code. (Not the other kind of wart. Promise.)

Run several coding agents in parallel, each in its own worktree, and review their work as it happens. CodeWart shows what changed and what it affects, and hands your review back to the agent. The agent can even wait for it.

Built for working with agents

Parallel worktrees

Give each agent its own worktree and keep them all open. Tabs are grouped by branch, sorted by latest activity, and show each branch's PR status, so you can review one agent while the others keep working.

Changes and their impact

The call chain shows every function the agent added, changed or deleted, wired from caller to callee, plus the untouched code that calls into it. Works in 15 languages with no setup.

Back to the agent, three ways

Comment on lines, functions or whole files. The agent can ask for your review and wait for it (wart review). Or send the review into its tmux, WezTerm or kitty pane, or copy it as markdown.

Follows the agent

Watches the worktree and jumps to the newest change the moment the agent commits or saves a file.

Hide the noise

One click hides tests, lockfiles, generated code, renames and whitespace-only changes, so you read the logic.

Review rounds on record

Every review you hand over is archived as a numbered round with date and time, so you can check that the agent addressed each comment before the next round.

Get started

  1. Install and open the app. On macOS, if it says the app can't be opened, right-click it and choose Open once, or run: 
    xattr -dr com.apple.quarantine /Applications/CodeWart.app
  2. Click "Install wart" in the top bar. This adds a small launcher to your PATH.
  3. Open any repo, worktree or folder of repos from your terminal: 
    wart .
    Running several agents? Give each its own worktree (git worktree add ../app.feature -b feature) and open them all.
  4. Let your agent ask for reviews. Install the Claude Code skill or add a few lines to your AGENTS.md, as shown below. The agent then runs wart review and waits until you send your review.

Review rounds with your agents

With wart review, an agent asks for your review and waits for it. No terminal plugins and no copy and paste: the agent stops, you review in CodeWart, and your comments come back to it as its next instructions.

The agent asks

When it finishes a step, the agent runs wart review -m "what changed, what to check". CodeWart opens its worktree, marks the tab and shows the message next to the diff.

You review

Comment on lines, functions or whole files and add overall notes. Then click Send to agent, or Approve if nothing needs to change.

The agent addresses it

It receives your review as markdown with file and line references, works through every comment and answers each one with wart answer: you see “solved” or its reply right under your comment. Then it asks for the next round.

Claude Code skill

The codewart-review skill teaches Claude when to ask for your review, how to keep waiting past its 10-minute command limit, and how to address and answer every comment. Install it with:

mkdir -p ~/.claude/skills/codewart-review
curl -fsSL -o ~/.claude/skills/codewart-review/SKILL.md \
  https://raw.githubusercontent.com/ivostrugar/CodeWart/main/skills/codewart-review/SKILL.md

Then ask for it in plain words:

  • Implement token rotation in src/session.ts, then get my review in CodeWart and address it.
  • Fix the flaky login test. Work in review rounds with me in CodeWart until I approve.
  • Refactor the router and ask for my review after each step.

Codex, Gemini CLI, Aider, Cursor… any agent

Add this to the repo's AGENTS.md (or CLAUDE.md, GEMINI.md, CONVENTIONS.md):

## Code review
When you finish a task, run `wart review -m "<what changed, what to check>"` and wait for my review
(re-run it if it exits 3). Address every comment it prints, answer each one with
`wart answer <review id>` (one line per comment: `1. solved: …` / `2. answered: …`), then ask for the next review.
If it prints APPROVED, you're done. Run `wart agent` for details.

The agent learns the rest from wart agent, which prints the agent guide: commands, exit codes and the review format.

Tip: one worktree per agent task, opened with wart ., lets you review one agent while the others keep working. Run wart review from a folder of worktrees to review one feature across several repos at once.
